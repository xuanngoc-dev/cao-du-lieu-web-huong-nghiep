Tải tài liệu phương thức tuyển sinh

Chọn trường, năm học, rồi dán JSON hoặc tải tài liệu đề án.
Dán một danh sách JSON. Dữ liệu được ghi cho từng năm học đã chọn. Có thể xem các cấu trúc được hỗ trợ bên dưới.

Mã phương thức và tổ hợp dùng chung. Mỗi mã trong phuong_thuc nhận cùng danh sách To_hop.

[
  {
    "STT": 1,
    "Ma_xet_tuyen": "7210404",
    "Ten_nganh": "Thiết kế thời trang",
    "Chi_tieu": 60,
    "phuong_thuc": [301, 410, 200, 100, 402],
    "To_hop": ["C01", "C03", "C04", "D01"]
  }
]

Phương thức có tổ hợp riêng. Mỗi phần tử phuong_thuc khai báo ma_phuong_thuc và to_hop của chính nó.

[
  {
    "ma_xet_tuyen": "7210404",
    "ma_nganh": "7210404",
    "ten_nganh": "Thiết kế thời trang",
    "chi_tieu": 60,
    "phuong_thuc": [
      { "ma_phuong_thuc": "301", "to_hop": ["C01", "C03"] },
      { "ma_phuong_thuc": "100", "to_hop": ["D01"] }
    ]
  }
]
